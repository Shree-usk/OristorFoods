---
name: create-test-cases
description: Generate test cases for a given code snippet or component. 
---

When this script is run, it will generate test cases for the given code snippet or component. The generated test cases will be based on the input and will cover the various scenarios to ensure comprehensive testing of the code snippet or component. The test cases will include edge cases, boundary conditions, and typical use cases to validate the functionality and robustness of the code.

Test case format
Each test case will be structured in the following format: 
1. Test Case ID: A unique identifier for the test case.
2. Test Case Description: A brief description of what the test case is intended to validate.
3. Input: The input data or parameters that will be used for the test case.
4. Expected Output: The expected result or behavior of the code snippet or component when provided with the input.
5. Severity: The level of impact the test case has on the overall functionality of the code snippet or component (e.g., Critical, High, Medium, Low).
